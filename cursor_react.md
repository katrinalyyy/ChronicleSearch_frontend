**5. Хуки (Hooks):**
- **useState** - управление состоянием в функциональных компонентах
- Замена `this.state` из классовых компонентов

**5.2. Жизненный цикл:**
- **Mounting**: constructor → getDerivedStateFromProps → render → componentDidMount
- **Updating**: getDerivedStateFromProps → shouldComponentUpdate → componentDidUpdate
- **Unmounting**: componentWillUnmount

**5.3. useEffect:**
- Заменяет componentDidMount, componentDidUpdate, componentWillUnmount
- Массив зависимостей `[]` - выполнится 1 раз при монтировании
- Cleanup функция в `return` - выполнится при размонтировании
- **Правила**: не вызывать в циклах/условиях, только в функциональных компонентах

**5.4. Практика:**
- Пример с `useState` для строк, массивов, boolean
- Пример с `useEffect` для разных сценариев
- Условный рендеринг с `&&`
